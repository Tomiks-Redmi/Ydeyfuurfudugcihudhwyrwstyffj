# ⚡ DroidForge — ADB & Fastboot Studio

Современная программа с графическим интерфейсом для прошивки Android-устройств и быстрой работы с командами **adb** и **fastboot**. Написана на **Python + PyQt6**, тёмная неоновая тема, всё выполняется асинхронно — интерфейс не зависает даже во время прошивки.

## 🎨 Интерфейс
- **Минималистичный дизайн**: нейтральная графитовая (или светлая) палитра, один акцентный цвет, плоские поверхности без градиентов, монохромные линейные SVG‑иконки вместо эмодзи, вкладки с подчёркиванием
- **Светлая и тёмная тема** (или «как в системе») + 7 цветов оформления — переключатель ☀/🌙 в шапке, `Ctrl+T`
- **Палитра команд `Ctrl+K`** — найдите что угодно по паре букв: страницу, инструмент, вкладку, перезагрузку, быструю команду, сценарий или действие, и выполните по Enter
- **Сворачиваемая консоль** (`Ctrl+J`) — в свёрнутом виде показывает только статус и последнюю строку, а при ошибке разворачивается сама
- **Боковое меню** с разделами, сворачивается до иконок (`Ctrl+B`); внизу — карточка подключённого устройства (режим, USB/Wi‑Fi, заряд)
- **Инструменты — сетка карточек** с описаниями, внутри инструмента — «хлебные крошки» и кнопка «← назад» (`Alt+←`)
- Вкладки‑«таблетки», плавные переходы между страницами, баннер на главной, если adb/fastboot не найдены
- **Мастер подключения** на главной, пока телефон не подключён: 4 шага + кнопки «Перезапустить ADB», «Wi‑Fi», «Драйвер»
- **Избранные команды** на главной — свои команды запускаются в один клик
- **История операций** (`Ctrl+H`, кнопка 🕘): статус, время и повтор любой прошлой операции
- Тонкая **полоса прогресса** под шапкой видна, даже когда консоль свёрнута

## ✨ Возможности

### 🏠 Обзор
- Автоматическое обнаружение устройств (ADB, Recovery, Sideload, Fastboot, Wi‑Fi) с уведомлениями о подключении
- Карточка устройства: модель, Android, патч безопасности, слот A/B, загрузчик, baseband, батарея и температура
- В режиме fastboot: продукт, статус разблокировки, текущий слот, fastbootd и т.д.
- Таблица всех свойств (`getprop` / `getvar all`) с поиском
- **Живой мониторинг**: ОЗУ, место на /data, нагрузка CPU, температура батареи
- Экспорт полного отчёта об устройстве в текстовый файл
- Перезагрузка в систему / recovery / bootloader / fastbootd / sideload / EDL / выключение

### ⚡ Прошивка
- **Фирменные скрипты прошивки**: в папке с прошивкой находятся `flash_all.bat`, `flash_all_except_storage.bat`, `flash_all_lock.bat`, `flash-all.sh` и т.п. — программа сама разбирает их `fastboot`‑команды (без запуска shell), проверяет модель устройства из скрипта, предупреждает о сбросе данных и блокировке загрузчика и выполняет по шагам. По умолчанию выбирается вариант «без удаления данных»
- **Архивы распаковываются сами**: можно сразу выбрать `.img.xz`, `.img.gz` или `.zip` (для раздела и GSI)
- **Один раздел**: определение раздела по имени файла, выбор слота (A / B / оба), `--disable-verity --disable-verification` для vbmeta, временная загрузка `fastboot boot`, стирание раздела
- **Прошивка из папки**: сканирует распакованную прошивку, сортирует образы в правильном порядке (bootloader → radio → vbmeta → boot → … → логические разделы), сама перезагружает загрузчик после bootloader/radio и переходит в **fastbootd** перед system/vendor/product, умеет сброс данных (`-w`)
- **Загрузчик**: `flashing unlock/lock`, `unlock_critical`, `oem unlock`, смена активного слота, `getvar`
- **Sideload / ZIP**: `adb sideload`, `fastboot update`
- **GSI**: мастер установки Generic System Image — vbmeta без проверки, переход в fastbootd, удаление product при нехватке места, прошивка system, сброс данных; проверка поддержки Treble
- **Защита от чужой прошивки**: если в папке есть `android-info.txt`, программа сверит кодовое имя устройства и предупредит при несовпадении
- Если телефон в режиме ADB, программа предложит перезагрузить его в bootloader и продолжит прошивку автоматически
- Опасные действия всегда требуют подтверждения

### 🚑 Восстановление
- **Не загружается (bootloop)** — шаги от безопасных к радикальным: переключение слота A↔B, удаление модулей Magisk (ждёт появления adb во время загрузки), возврат стоковых boot / init_boot / vbmeta в оба слота, recovery, очистка cache, сброс данных, полная перепрошивка; подсказки для «hard brick» (EDL, BROM, Odin)
- **Восстановление разделов из бэкапа** — через fastboot или root `dd`, с пометкой разделов IMEI/EFS
- **Слоты A/B** — текущий слот, «успешный / неудачный / попыток осталось» для каждого слота, переключение
- **Кастомный recovery** (TWRP, OrangeFox) — временная загрузка, прошивка в recovery или vendor_boot
- **Настройки и приложения** — бэкап базы настроек Android в JSON и восстановление (с пропуском привязанных к устройству ключей), установка всех APK из папки

### 📱 ADB инструменты
- **Приложения**: менеджер **разрешений** (выдать / отозвать / сбросить), открыть настройки приложения или страницу в Play Маркете; список (пользовательские / системные / отключённые), поиск, запуск, остановка, извлечение APK, очистка данных, отключение, удаление (в т.ч. системных через `pm uninstall --user 0`)
- **Файлы**: файловый менеджер устройства — навигация, скачивание, загрузка (drag & drop), новые папки, переименование, удаление
- **Установка APK**: перетащите файлы или папку, опции `-r -d -g -t`, split APK (`install-multiple`), **бандлы `.xapk` / `.apks` / `.apkm`** (с копированием OBB), **установка по ссылке**
- **Процессы**: живой список с CPU и памятью, сортировка, фильтр, остановка приложения, kill (в т.ч. через root)
- **Порты**: `adb forward` / `adb reverse` — список, добавление, удаление, готовые варианты (Chrome DevTools, React Native, локальный сервер)
- **Редактор файлов на телефоне**: открыть текстовый файл во встроенном редакторе и сохранить обратно (в т.ч. системный — через root)
- **Экран**: скриншот с предпросмотром, запись экрана, пульт (Домой, Назад, Питание, Громкость…), ввод текста, **зеркало экрана через scrcpy** (если он установлен).
  **Управление мышью прямо по скриншоту**: клик — тап, перетаскивание — свайп, удержание — долгое нажатие, после клика можно **печатать с клавиатуры ПК** (Enter, Backspace, стрелки тоже работают); режим **Live** обновляет экран ~1 раз в секунду — получается управление телефоном без scrcpy
- **ADB по Wi‑Fi**: `tcpip` + `connect`, определение IP, сопряжение по коду (Android 11+)

### 🧰 Инструменты
- **Яркость и громкость** ползунками, переключатели режима разработчика (границы элементов, профиль GPU, «не хранить activity»)
- **Твики**: плотность (DPI), разрешение, частота обновления, тайм‑аут экрана, масштаб шрифта, скорость анимаций, тёмная тема, показ касаний; **Private DNS** с пресетами (AdGuard — блокировка рекламы во всех приложениях, Cloudflare, Google, Quad9, свой); Wi‑Fi / данные / авиарежим / Bluetooth
- **Редактор настроек Android**: просмотр, поиск, изменение, добавление и удаление ключей в `settings system / secure / global`
- **Сценарии**: многострочные макросы (`# комментарии`, `sleep N`, `echo текст`), сохранение, импорт/экспорт, запуск на текущем или **на всех устройствах сразу**
- **Диагностика**: «Железо» (SoC, частоты ядер, память, экран, сенсоры), отправка уведомления на телефон, здоровье батареи (ёмкость в %, циклы зарядки), что занимает место, проверка интернета, bugreport, журнал сбоев, температуры датчиков, топ процессов, обозреватель `dumpsys` с поиском по тексту, открыть ссылку / номер / карту на телефоне, быстрый переход в скрытые меню настроек (в т.ч. тест сети *#*#4636#*#*)
- **Payload Dumper** — извлекает `boot.img`, `init_boot.img`, `vbmeta.img` и любые другие образы из официальной OTA‑прошивки (ZIP с `payload.bin` или сам `payload.bin`). Написан на чистом Python, проверяет SHA‑256 каждого блока и итогового образа. Для образов, сжатых zstd, нужен `pip install zstandard`
- **Root через Magisk** — мастер из 5 шагов: стоковый образ → установка Magisk → отправка на телефон → забрать `magisk_patched*.img` → прошивка (с автоперезагрузкой в bootloader)
- **Бэкап** — образы разделов через `dd` (нужен root), с пометкой критичных для IMEI разделов (EFS, modemst, persist, nvdata); копирование папок с `/sdcard`; APK всех пользовательских приложений; восстановление папки на телефон
- **Debloat** — готовые списки мусорных приложений Xiaomi/MIUI/HyperOS, Samsung, Facebook и Google, проверка установленных, удаление для пользователя, отключение и **восстановление** (`cmd package install-existing`)
- **Контрольные суммы** — MD5 / SHA‑1 / SHA‑256 любого файла и сравнение с ожидаемой суммой

### 🎯 Перетаскивание на окно
Бросьте файл в любое место окна: `.apk` установится, `.img` откроется в прошивке раздела, папка — в прошивке из папки, OTA‑zip — в Payload Dumper, обычный `.zip` — в sideload, любой другой файл — в проверку контрольной суммы.

### 🚀 Быстрые команды
Библиотека из 50+ готовых команд по категориям с поиском. Можно добавлять **свои команды** (в т.ч. цепочки через `&&`) — они сохраняются.

### 📜 Logcat
Живой лог с цветовой подсветкой уровней, кнопка **«Только сбои»** (FATAL EXCEPTION, ANR, нативные падения), фильтр по уровню, тексту / regex и пакету, сохранение в файл.

### 🖥 Консоль
Всегда под рукой внизу окна. Галочка **«📡 На все»** выполняет команду на всех подключённых устройствах сразу. Цветной вывод, ввод любых команд (`adb …`, `fastboot …` или коротко `shell ls`), история по ↑/↓, автодополнение, прогресс очереди и кнопка «Стоп». Серийный номер выбранного устройства подставляется автоматически.

### ⚙️ Настройки
Автопоиск adb/fastboot (PATH, Android SDK, папка `platform-tools` рядом с программой), ручной выбор путей и **скачивание официальных platform-tools от Google в один клик**. **Автозапуск сценария при подключении устройства**. Светлая/тёмная тема и 8 акцентных цветов, уведомления в системном трее после долгих операций. Весь вывод консоли пишется в журнал сессии (`~/.droidforge/logs`, хранятся последние 30).

## 🚀 Запуск

```bash
pip install -r requirements.txt
python main.py
```

Нужен Python 3.9+. Если adb/fastboot не установлены — откройте **Настройки → «Скачать и установить»**.

### Windows
Для работы fastboot может понадобиться [Google USB Driver](https://developer.android.com/studio/run/win-usb) или драйвер производителя.

### Linux
Если устройство отображается как «Нет прав», установите udev-правила: `sudo apt install android-sdk-platform-tools-common` и переподключите кабель.

### Сборка в .exe (по желанию)
```bash
pip install pyinstaller
pyinstaller --noconsole --name DroidForge --add-data "droidforge/ui/assets;droidforge/ui/assets" main.py
```
(на Linux/macOS вместо `;` используйте `:`)

## 📂 Структура
```
main.py                     точка входа
droidforge/
  app.py                    главное окно, общие функции для страниц
  core/
    runner.py               асинхронный запуск команд (очередь QProcess)
    devices.py              мониторинг устройств
    tools.py                поиск и загрузка platform-tools
    commands.py             разбор команд и библиотека быстрых команд
    config.py               настройки (~/.droidforge/config.json)
    payload.py              распаковщик OTA payload.bin
    flashscript.py          разбор фирменных скриптов прошивки (flash_all.bat / flash-all.sh)
    workers.py              фоновые потоки (payload, хэши)
    logfile.py              журнал сессии
  ui/
    theme.py, icons.py, widgets.py, console.py, palette.py, history.py
    pages/                  dashboard, flash, rescue, adb_tools, adb_extra, toolbox, toolbox_extra, quick, logcat, settings
```

## ⚠️ Предупреждение
Прошивка, разблокировка загрузчика и стирание разделов могут привести к потере данных или неработоспособности устройства. Вы действуете на свой страх и риск — всегда делайте резервные копии и используйте прошивки именно для своей модели.
